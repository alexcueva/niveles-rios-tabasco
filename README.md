# Niveles de Ríos Tabasco

Dashboard con el histórico y monitoreo de niveles de los 14 ríos/estaciones de Protección Civil Tabasco, generado a partir de los boletines diarios.

## Contenido

- Mapa de estaciones sobre la geografía real de Tabasco y estados vecinos.
- Tablero de estado con el nivel más reciente de cada estación.
- Series de tiempo históricas con bandas de climatología (percentiles P10–P90).
- Tabla de datos con los valores más recientes de cada río.

## Cómo verlo

Este repositorio se publica con GitHub Pages. Una vez activado en la configuración del repositorio (Settings → Pages), el dashboard queda disponible en:

https://alexcueva.github.io/niveles-rios-tabasco/

## Nota

Este archivo (`index.html`) es una foto fija de los datos al momento de generarlo. Para actualizarlo hay que volver a generar el archivo con los datos más recientes y subirlo (`git add`, `git commit`, `git push`).
